# NexusAI

Multi-Provider AI Orchestration Platform.

NexusAI aims to provide a unified API for integrating,
managing and orchestrating multiple AI providers.

## Tech Stack

- Python
- FastAPI
- Pydantic
- HTTPX
- React
- TypeScript
- PostgreSQL
- Redis
- Docker

## Current Features

- FastAPI backend
- Modular application architecture
- Provider abstraction
- Health monitoring
- API documentation
- Initial automated tests

## Project Status

Under active development.
